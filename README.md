### 👨‍💻 关于我

> 把零散的想法，做成长期可用的工具。

写了七年 Java，长期在后台跟服务、数据打交道。前端其实很早就碰过，只是一直做得不多。AI 兴起之后，把想法做出来容易多了，这两年才往全栈走。工作之外，家里的 NAS 折腾得最多，装服务、调网络，碰到没见过的东西总想先试一下。

- 🛠️ **专注方向**：后端研发、Web 全栈、桌面端；NAS / 家庭服务器与 Homelab
- 💡 **开发哲学**：关注长期维护与使用体验，喜欢把复杂流程收敛为简单、稳定、可重复的工具
- 🚀 **主要作品**：[**BUJIC Echo**](https://echo.bujic.cc/)（Android 本地离线音频 AI 应用，语音转写·声音克隆·离线翻译）
